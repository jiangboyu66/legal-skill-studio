# ADR 0004：规则包是受审核的独立实体

- 状态：已采纳（v2）

## 背景
法律结论的依据是规则。若规则只是工作流里的一段文本参数，就无法证明“这次运行依据的是谁、在什么时候批准的哪一版规则”。

## 决策
规则包独立存储与版本化；每条规则带来源、核实程度（原文 / 转述 / 未核实）与适用渠道；批准时审核人签署声明（姓名、执业资格、复审截止日期）；正式运行只能使用已批准且未过期的版本（组织策略可放宽，但运行上会提示“未经审核”）；运行记录与报告保存规则包版本和审核声明。

## 备选方案
把规则写进 Skill 的任务说明：简单，但无法单独审核、复用和追溯。

## 代价
多了一个审核环节；示例规则包上线前必须由客户的法律审核人逐条核对。

## 何时重新评估
若接入授权的法律数据库，规则包可改为“引用外部条文 + 本组织解释”的结构，审核流程不变。
