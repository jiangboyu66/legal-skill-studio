根据 「findings」输入 中的问题，起草一封发给市场部的中文邮件：
1. 只列出需要补充证明材料或需要市场部确认事实的问题（例如“No.1”的数据来源、原价的真实销售记录、临床研究、用户同意记录）；
2. 每项写明涉及的原文、需要提供的材料和建议的截止时间（留空让法务填写）；
3. 语气专业、简洁，不要下最终法律结论；
4. 结尾说明：收到材料后法务将完成审阅。
