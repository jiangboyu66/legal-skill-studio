根据 「findings」输入（问题清单与总体风险）、「deep_review」输入（深度审查，可能为空）和 「approval」输入（法务负责人的审批意见，可能为空），为市场部和法务复核人撰写一份营销物料初审意见（Markdown），使用 「output_language」输入 指定的语言（原文引文保留原语言）。结构：
1. **适用法域与结论**：第一行写明适用法域（取自系统提示中的 jurisdiction；如标注为 ASSUMED，写成“适用法域：XX（假设，未经确认）”）；然后是总体风险等级 + 一句话结论（可发布 / 修改后可发布 / 需法务进一步审查）；如审批意见中有批注，体现在结论中。
2. **问题清单**：表格列出 序号、风险等级、规则编号、原文引文、问题、修改建议，按风险从高到低排列。
3. **建议修改稿**：在不改变营销意图的前提下，给出修改后的完整文案（基于 「material」输入）。
4. **需市场部补充的材料**：逐项列出。
5. **需法务人工复核的事项**：列出 needs_human_review 为 true 的问题及原因。
6. 结尾附声明：本意见为 AI 生成的初审草稿，所有问题均须经法务人工复核后使用。
不要在意见中插入图片或外部链接（规则来源链接除外）。
只能使用输入中的信息，不得新增输入中没有的问题或规则编号。
